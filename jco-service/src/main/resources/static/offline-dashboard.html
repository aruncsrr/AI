How to Run Locally
1
Build the JAR (one-time)
Open Terminal in the project folder:
cd ~/Desktop/sap-ai-assistant/jco-service && mvn clean package
Takes ~2 min. Produces target/jco-service-1.0.0.jar. Requires Java 17 and Maven.
2
Start the web server
cd ~/Desktop/sap-ai-assistant && ./start-sap-assistant.sh
This launches the AI chat UI. Browser opens automatically at http://localhost:8080.
Bookmark that URL — it works offline (SAP calls optional).
3
Use as MCP server (for Claude Code CLI)
./start-sap-assistant.sh --mcp
Add to Claude Code's MCP config (~/.claude/mcp_settings.json). 88 tools become available in Claude Code conversations.
4
Run the knowledge pipeline (one-time, SAP required)
Start the Java server first (step 2), then in a second terminal:
cd ~/Desktop/sap-ai-assistant/pipeline
node cdd-crawler.js --phase 1   — discovers all objects (~30 min)
node cdd-crawler.js --phase 2 --concurrency 5   — downloads code (~2–4 hrs)
node cdd-crawler.js --phase 3   — where-used analysis (~30 min)
node graph-builder.js && node export-builder.js && node sync-java-cache.js
After this, everything works fully offline.
5
Resume an interrupted crawl
node fix-manifest.js && node cdd-crawler.js --phase 2 --concurrency 5
The crawler resumes from where it stopped — already-downloaded objects are skipped.

📘 SAP Objects Reference
Object Type Type Code Description ADT Endpoint Pattern MCP Tool(s)
🔷 Class CLAS ABAP OO class with methods, attributes, and local types /sap/bc/adt/oo/classes/{name} GetClass, SaveClass, GetClassInclude, SaveClassInclude, SaveClassTestInclude
🔹 Interface INTF ABAP OO interface defining method signatures and constants /sap/bc/adt/oo/interfaces/{name} GetInterface, SaveInterface
📄 Program PROG Standalone ABAP report program (executable) /sap/bc/adt/programs/programs/{name} GetProgram, SaveProgram
📂 Function Group FUGR Container for function modules with shared global data /sap/bc/adt/functions/groups/{name} GetFunctionGroup, SaveFunctionGroup
⚡ Function Module FUGR/FF Reusable function within a function group (RFC-enabled possible) /sap/bc/adt/functions/groups/{group}/fmodules/{name} GetFunctionModule, SaveFunctionModule
📎 Include PROG/I Reusable include program (inserted via INCLUDE statement) /sap/bc/adt/programs/includes/{name} GetInclude, SaveInclude
🔮 CDS View DDLS Core Data Services view (DDL source) for data modeling /sap/bc/adt/ddic/ddl/sources/{name} GetCDSView, PreviewCDSView
🗃️ Table TABL DDIC transparent table (database table definition) /sap/bc/adt/ddic/tables/{name} GetTable, GetTableFields, PreviewTableData
🧱 Structure TABL/S DDIC structure type (no database table, used as type) /sap/bc/adt/ddic/structures/{name} GetStructure, GetStructureFields
🏷️ Data Element DTEL Semantic type with labels, documentation, and domain reference /sap/bc/adt/ddic/dataelements/{name} GetDataElement
🎯 Domain DOMA Technical type with value range and fixed values /sap/bc/adt/ddic/domains/{name} GetDomain
📐 Behavior Definition BDEF RAP behavior definition for business object (CRUD, actions, validations) /sap/bc/adt/bo/behaviordefinitions/{name} GetBehaviorDefinition, SaveBehaviorDefinition
🔗 Service Definition SRVD RAP service definition exposing CDS entities for consumption /sap/bc/adt/ddic/srvd/sources/{name} GetServiceDefinition, SaveServiceDefinition
🌐 Service Binding SRVB RAP service binding (OData V2/V4 protocol binding) /sap/bc/adt/businessservices/bindings/{name} GetServiceBinding
🏢 BOPF Business Object BOBF Business Object Processing Framework (nodes, actions, determinations) /sap/bc/adt/bopf/businessobjects/{name} GetBopfBusinessObject
📦 Package DEVC Development package grouping related objects (transport layer) /sap/bc/adt/repository/nodestructure GetPackageContents
💬 Message Class MSAG Collection of numbered messages for user communication (T100) /sap/bc/adt/messageclass/{name} GetWhereUsed, Search
🔎 Search Help SHLP F4 value help for input fields (elementary or collective) /sap/bc/adt/ddic/searchhelps/{name} GetWhereUsed, Search
