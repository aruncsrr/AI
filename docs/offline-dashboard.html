How to Run Locally
1
Build the JAR (one-time)
Open Terminal in the project folder:
cd ~/Desktop/sap-ai-assistant/jco-service && mvn clean package
Takes ~2 min. Produces target/jco-service-1.0.0.jar. Requires Java 17 and Maven.
2
Start the web server
cd ~/Desktop/sap-ai-assistant && ./start-sap-assistant.sh
This launches the AI chat UI. Browser opens automatically at http://localhost:8080.
Bookmark that URL — it works offline (SAP calls optional).
3
Use as MCP server (for Claude Code CLI)
./start-sap-assistant.sh --mcp
Add to Claude Code's MCP config (~/.claude/mcp_settings.json). 88 tools become available in Claude Code conversations.
4
Run the knowledge pipeline (one-time, SAP required)
Start the Java server first (step 2), then in a second terminal:
cd ~/Desktop/sap-ai-assistant/pipeline
node cdd-crawler.js --phase 1   — discovers all objects (~30 min)
node cdd-crawler.js --phase 2 --concurrency 5   — downloads code (~2–4 hrs)
node cdd-crawler.js --phase 3   — where-used analysis (~30 min)
node graph-builder.js && node export-builder.js && node sync-java-cache.js
After this, everything works fully offline.
5
Resume an interrupted crawl
node fix-manifest.js && node cdd-crawler.js --phase 2 --concurrency 5
The crawler resumes from where it stopped — already-downloaded objects are skipped.

Troubleshooting
ProblemFix
Server not reachable / status shows OfflineRun ./start-sap-assistant.sh in a terminal. Keep that terminal window open.
JAR not found error on startcd jco-service && mvn clean package, then retry.
cdd_local_get_code returns empty / not foundRun node sync-java-cache.js from the pipeline/ folder after completing crawl phase 2.
Crawl interrupted — want to resumenode fix-manifest.js && node cdd-crawler.js --phase 2 --concurrency 5
/cdd-knowledge returns "Run export-builder.js first"node graph-builder.js && node export-builder.js
POST /api/pipeline/reload-cache → 404Rebuild JAR: cd jco-service && mvn clean package, restart server.
JCo SNC error / cannot connect to ISDRun kinit first to get a Kerberos ticket. Check SNC partner name in .sap-systems.json.
Port 8080 already in useUse ./start-sap-assistant.sh --port 9090 and bookmark the new URL.
